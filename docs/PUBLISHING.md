# 公開ガイド

公開済みページ: [traQ Flow — 連投をまとめる](https://greasyfork.org/ja/scripts/596315)（v0.1.1、2026-09-18）。以降の更新はこの掲載ページの「更新」から行ってください。

## 推奨: Greasy Fork

配布ファイル1つで導入でき、同じコードの更新配布が容易なので、最初の掲載先に適しています。ユーザー側にはTampermonkeyなどの管理拡張が必要です。

1. [Greasy Fork](https://greasyfork.org/ja) にログイン。
2. [新しいスクリプトを投稿](https://greasyfork.org/ja/script_versions/new) を開く。初回は「スクリプトを書いたので、他の人に共有したい」を選ぶ。
3. `dist/traq-flow.user.js` の全文をコード欄に貼り付ける。
4. 以下の説明文を設定し、コード・対象サイト・MITライセンスを確認して公開する。
5. 掲載URLをREADMEの導入リンクに追加する。更新時はバージョンを上げ、同じ掲載ページを更新する。

### 掲載用説明文

traQで短時間に送った文章を、直近の自分のメッセージへの追記に変えます。初期値60秒、1〜600秒に設定できます。他人の連続した発言も、本文やスタンプを残したまま名前・アイコンを表示上まとめられます。

右上のFlowボタンで設定できます。「自分の連投を前の投稿に追記」「連続した発言の表示をまとめる」は個別に無効化でき、「次の1回は新規投稿」も選べます。

追記はサーバー上の編集であり、全員に反映されます。表示の結合は自分のブラウザだけです。対応サイトはq.trap.jpのブラウザ版。外部送信、広告、APIトークンの設定はありません。非公式の拡張です。別端末との同時編集は完全には防げません。

### 方針

配布ファイルは読みやすい非圧縮JavaScriptで、外部依存・遠隔ロードを含みません。[コード規則](https://greasyfork.org/en/help/code-rules) と [メタデータ規則](https://greasyfork.org/en/help/meta-keys) を参照。

## Chrome Web Store

一般利用者は拡張単体で導入できる利点があります。一方、開発者アカウント登録・ストア申請・審査が必要です。

1. [Chrome Web Store開発者ダッシュボード](https://chrome.google.com/webstore/devconsole) で開発者登録を完了する。
2. `dist/chrome/` の中身をZIP化して新規アイテムとしてアップロードする。
3. ストア用アイコン・実traQ上のスクリーンショットを追加する。テスト画面の画像を実サービスの画面として使わない。
4. 掲載説明とプライバシーポリシーURL（このリポジトリの `docs/PRIVACY.md`）を入力する。
5. 単一目的は「traQの連投の追記と表示整理」。MAIN worldで動く理由は、traQクライアントのXHR/fetchを捕捉し、Vueの描画ツリーを読み取るため。
6. 閲覧・処理するデータはメッセージ本文とユーザーID。第三者収集・外部送信なし。ストアのデータ利用質問には実装と一致するよう回答する。
7. 実traQで最終確認して審査へ提出する。

ビルド済みChrome拡張はローカル導入用です。ストア申請に必要なアカウント情報や宣伝素材は含みません。
