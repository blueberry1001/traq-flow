# プライバシーポリシー

更新日: 2026-09-18

traQ Flowは、連投の追記と表示整理のため、利用者がログインしているtraQ上で現在のユーザー情報、チャンネルの直近メッセージ、編集対象本文を読み取り、自分のメッセージを編集します。他人のメッセージは表示のみを変更します。

これらの情報を開発者や第三者のサーバーへ送信しません。通信先は開いているtraQと同じオリジンのみです。広告、分析、行動追跡、リモートコードを含みません。

有効/無効と秒数の設定を、そのtraQオリジンのlocalStorageの `traq-flow.settings.v1` に保存します。メッセージ本文の一時キャッシュはタブのメモリだけに保持し、閉じると破棄されます。サイトデータの削除で設定も削除できます。

ブラウザ拡張の実行対象は `https://q.trap.jp/*` だけです。追加のAPIトークン、全サイトの閲覧権限、タブ履歴、ブラウザ同期、外部サービスへのアクセスは要求しません。

問い合わせは [GitHub Issues](https://github.com/blueberry1001/traq-flow/issues) を利用してください。非公開チャンネルの本文、Cookie、トークンをIssueに添付しないでください。
